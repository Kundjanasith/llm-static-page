THE SETUP

From files to
live website.

Upload the included files to a GitHub repository, enable GitHub Pages, and share your URL. Visitors with compatible hardware can activate AI.

  1. 01
    Upload

    Commit index.html, styles.css, and app.js to your repository.

  2. 02
    Publish

    In Settings → Pages, deploy from main and /(root).

  3. 03
    Chat

    Open the site, select “Load AI model”, and start chatting when the download finishes.
